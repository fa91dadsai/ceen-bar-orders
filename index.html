How it works

Choose a section → category → item. Switch between Step-by-step and Quick list without losing quantities. Order / Stock (for example 2 / 12) means 2 requested and 12 in stock, not a fraction. An asterisk marks unconfirmed file stock. A dash means stock is missing or unclear.

Skip remaining preserves your quantities and marks untouched zero-quantity items as skipped. Checked and skipped counts are separate; revisit skipped items from the category summary.

Enter the required quantity, then tap Next. A quantity of zero is left out of the order.


Keep your catalog up to date. Add sections, categories and items. Edit an item's name, category, default order unit or pack size. Use Edit stock to record a count and its unit.


Stock and orders are separate. Preparing or sharing an order does not reduce stock. A source-file stock value has no confirmed unit or date. A missing value is shown as “Not recorded”, never zero. Values such as 10/8 need verification.


WhatsApp. Review the exact message, then copy it or open WhatsApp. You choose the recipient and send the message yourself. Stock is excluded unless you select “Include stock”.


Delete and restore. Delete an item, or a category/section with its contents. Entries move to Trash and are removed from the current order. Restore from Trash; quantities return only within the same order.

New order keeps your catalog and stock. Backup includes catalog changes, stock history and the current draft. Restore replaces all local app data after confirmation. Older order-only backups are also supported and retain the current catalog.


Data is stored on this device in this browser when available, not synced between devices. The hosted version supports installation from Order tools → Install app / Add shortcut. Back up before moving the file or clearing browser data. Stock history is local and is not a protected multi-user audit log.
